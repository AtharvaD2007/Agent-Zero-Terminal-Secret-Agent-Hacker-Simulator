## Project description

Agent Zero Terminal is a single-page, fictional hacker-terminal simulator made for a college AI Coding Lab assignment. It demonstrates interactive web features using plain HTML, CSS, and JavaScript. The scan, access progress, and decoded mission messages are visual simulations only: the project does not access or modify real systems.

## Features

- Animated Matrix-style falling characters drawn with the HTML Canvas API.
- Mission Control with a timestamped terminal log, simulated system scan, fictional signal decryption, and Clear Log button.
- A visual progress simulation with a percentage counter, completion status, and Reset button.
- A cipher puzzle that checks the answer by shifting letters backward, with input validation and a hint.
- Optional electronic beeps generated by the browser Web Audio API. Sound is off by default.
- Responsive layout, scanline effects, glowing terminal details, and a blinking cursor.
- A keyboard easter egg: press **M** outside a text field to fade the Matrix rain on or off.
- Three automated `clampPercent` checks in the browser console.

## Technologies used

- HTML5
- CSS3
- Vanilla JavaScript
- HTML Canvas API
- Web Audio API

No external packages, libraries, APIs, databases, or backend services are required.

## Open the project locally

1. Download or clone this repository.
2. Make sure `index.html` and `README.md` are in the same folder.
3. Open `index.html` in Google Chrome. You can double-click the file or choose **Open with → Google Chrome**.
4. The simulator runs locally in the browser; no install or web server is needed.

## How to play the cipher mini-game

1. Read the encrypted message: **DPEF**.
2. Shift each letter one position backward in the alphabet. For example, **D** becomes **C**.
3. Enter your decoded message and choose **Check Cipher**. The answer is **CODE**.
4. Answers are checked without regard to uppercase or lowercase. Submitting an empty answer displays a prompt instead of an error.
5. Choose **Hint** if you need a reminder of the shift.

## Check the three automated tests

1. Open `index.html` in Chrome.
2. Open Chrome DevTools: **View → Developer → JavaScript Console** (or press **Ctrl+Shift+J** on Windows/Linux or **Command+Option+J** on macOS).
3. Find the message `clampPercent checks complete — all three assertions should pass.`
4. The three `console.assert()` checks cover a normal value, zero and empty input, and a negative value. If an assertion fails, the console will report it.
